# Contexto local e colaboração opcional pelo GitHub

Em 26/10/2026, Matheus aprovou Q6–Q9 no chat de desenho da arquitetura: o Compor mantém projetos locais e oferece envio opcional ao GitHub de memórias, preferências, skills e projeto editável completo, incluindo recursos necessários à retomada. Credenciais, logs, caches e exportações reproduzíveis ficam fora desse conjunto.

O salvamento local é automático; o envio remoto é uma opção por contexto. Contribuições compartilhadas passam por propostas e revisão antes de integrarem a base vigente; conflitos preservam as versões, sem sobrescrita silenciosa. Essa escolha usa o GitHub como superfície de colaboração assíncrona, com o custo de administrar versões, revisão e crescimento do histórico de recursos, em vez de criar colaboração hospedada própria nesta versão.

A memória distingue os escopos pessoal, marca ou cliente, produto e campanha; correções de peça só são promovidas por escolha explícita. Skills são instruções declarativas editáveis e versionadas. Topologia dos repositórios, papéis de revisão, fluxo de autenticação e formato final dos projetos continuam abertos; esta decisão não os antecipa nem comprova implementação.
